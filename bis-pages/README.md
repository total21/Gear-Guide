# BiS input files

Put BiS lists here, then run `npm run import-bis`. Files other than this README are git-ignored.

Quickest: copy a BiS table from the spec's Wowhead page
(`https://www.wowhead.com/guide/classes/<class>/<spec>/bis-gear`) and paste it into a text
file named after the spec, e.g. `outlaw-rogue.txt`. Put a heading line ("Overall BiS",
"Raid BiS", "Mythic+ BiS") before each table if you paste more than one. See the main README.

Saved pages ("Webpage, HTML only") from Wowhead, Icy Veins or Archon also work.
