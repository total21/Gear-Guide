# Saved BiS pages

Put BiS pages saved from your browser here, then run `npm run import-bis`.
Files in this folder (other than this README) are git-ignored.

1. Open the spec's BiS page:
   - Wowhead (default): `https://www.wowhead.com/guide/classes/<class>/<spec>/bis-gear`
   - Icy Veins: `https://www.icy-veins.com/wow/<spec>-<class>-pve-<role>-gear-best-in-slot`
   - Archon: the spec's Mythic+ or raid "Gear & Tier" page
2. Check the page says Patch 12.1 or later / Midnight Season 2.
3. Save it: Ctrl+S / Cmd+S → "Webpage, HTML only". Any file name works; the page URL inside the file identifies the spec.
